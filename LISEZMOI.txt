VÉDÉ Terrain, version installable hors connexion (v1.6.0)
=====================================================

Ce dossier contient l'application complète. Une fois installée sur la
tablette, elle s'ouvre et fonctionne sans réseau. Les données (études,
dossiers, anomalies, photos) restent dans la tablette : rien n'est
envoyé sur Internet.

MISE EN LIGNE SUR GITHUB PAGES (une seule fois, 15 minutes environ)
1. Créez un compte sur https://github.com si vous n'en avez pas.
2. Créez un dépôt : bouton New repository, nom « vede-terrain »,
   visibilité Public (le dépôt ne contient que le code de l'application,
   jamais vos données de visite).
3. Dans le dépôt : Add file > Upload files. Glissez TOUT le contenu de ce
   dossier (index.html, sw.js, manifest.webmanifest et les dossiers lib,
   fonts, icons, croquis), pas le dossier lui-même. Validez avec Commit changes.
4. Settings > Pages > Build and deployment : Source « GitHub Actions ».
   Le fichier .github/workflows/mise-en-ligne.yml publie le site à chaque
   mise à jour de la branche main.
5. Après une à deux minutes, l'adresse s'affiche en haut de la page
   Pages : https://VOTRE-COMPTE.github.io/vede-terrain/

INSTALLATION SUR LA TABLETTE
1. Ouvrez l'adresse dans Chrome (Android) ou Safari (iPad), connecté.
2. Chrome : menu ⋮ > « Installer l'application » ou « Ajouter à l'écran
   d'accueil ». Safari : bouton Partager > « Sur l'écran d'accueil ».
3. Lancez l'application une fois depuis son icône, toujours connecté.
   Elle est ensuite utilisable sans réseau.

ÉTUDES ET DOSSIERS SANS TABLEAU
- Accueil > « Créer une étude à la main » : donnez un nom, puis ajoutez
  les dossiers un par un (numéro, adresse, code postal et ville). Le
  propriétaire et la personne rencontrée se saisissent ensuite dans la
  fiche contact de chaque dossier.
- Dans toute étude, importée ou non, le bouton « Dossier » de la liste
  (ou « Ajouter un dossier » dans le menu de l'étude) ajoute un dossier.
  Un dossier créé à la main peut être modifié (numéro, adresse) ou
  supprimé depuis sa page ; les dossiers du tableau, non.
- Un tableau Excel peut être importé plus tard (menu de l'étude) : les
  dossiers sont rapprochés par numéro. Un dossier créé à la main dont le
  numéro figure dans le tableau en prend les informations (l'aperçu
  signale une adresse différente) ; les autres sont conservés tels quels.
  Les exports comportent une dernière colonne « Dossier créé à la main ».

CROQUIS DE TERRAIN (facultatif)
- Réglages > « Utiliser le croquis de terrain » (coché d'origine). Décoché,
  l'application fonctionne comme avant (pages, constat, exports) ; les
  croquis déjà dessinés restent sur la tablette et dans les sauvegardes,
  et les anomalies qu'ils ont créées restent dans les dossiers, avec leurs
  préconisations.
- Dans un dossier : « Commencer le croquis ». Choisissez le fond de plan :
  un plan cadastral DXF déjà chargé dans l'étude, un DXF de la tablette
  (cadastre.gouv.fr), ou aucun pour l'instant. Le fond reste sur la
  tablette et sert à tous les dossiers de l'étude.
- On pose les équipements (WC, évier, descentes…), les regards, la boîte
  de branchement et les collecteurs, puis on les relie par des tronçons.
  L'application en déduit où chaque eau se rejette.
- Les anomalies déduites du dessin (EU vers EP, EP vers EU, fosse, descente
  non visitable, tampon béton…) rejoignent la liste du dossier, avec les
  mêmes numéros (A1, A2…) que les bulles du plan : la fiche Préco, le
  constat et les exports les reprennent comme les autres. Une anomalie
  « à arbitrer » ou « écartée » sur le croquis n'entre pas dans le
  dossier. Une anomalie saisie à la main dans le dossier peut être placée
  sur le plan (« Placer sur le croquis »).
- Tant qu'on n'y touche pas, une anomalie déduite suit le dessin (texte mis
  à jour, retirée si le dessin ne la produit plus). Dès qu'on la modifie
  (texte, photo, localisation), c'est elle qui fait foi : le dessin ne la
  change plus et ne la retire jamais sans demander : si le dessin ne la
  produit plus, le dossier rappelle de la vérifier ; la placer sur le plan
  la confirme. Une anomalie supprimée dans le dossier est écartée sur le
  croquis.
- Supprimer un croquis (Réglages du croquis) : on choisit de retirer aussi
  les anomalies qu'il a créées et que personne n'a modifiées, ou de les
  garder dans la liste du dossier, sans lien avec un plan.
- Constat : « Reprendre du croquis » (section Installations privatives)
  remplit le nombre, le raccordement et les méthodes des installations
  dessinées, sans remplacer ce qui a été saisi. Ensuite ces valeurs suivent
  le croquis tant qu'on n'y touche pas. Les écarts entre le croquis et le
  constat sont rappelés avant la signature. Un constat signé n'est jamais
  modifié.
- Aides au dessin (Réglages, ou bouton aimant dans le croquis) : traits
  parallèles au côté de bâti le plus proche, angles droits, accroche aux
  coins et façades, fin automatique d'un tronçon sur un objet, tracé en
  glissant le doigt, outil Relier en L. Chacune se désactive, et toutes
  ensemble par « Aides activées ».
- Sorties : plan de l'état des lieux et plan d'avant-projet en PDF, plan
  DXF pour la DAO (dans le croquis, « Sorties »), « Plan PDF » sur la page
  du dossier. L'export de l'étude joint le plan PDF dans le dossier.

SAUVEGARDE
- Effacer les données du navigateur ou désinstaller l'application efface
  aussi les études. Exportez chaque étude régulièrement (menu de l'étude >
  Exporter l'étude complète) : le fichier ZIP contient les fiches, les
  photos, les plans, le tableau récapitulatif et une sauvegarde
  restaurable sur n'importe quel appareil (accueil > Restaurer une
  sauvegarde), croquis et fonds de plan compris.

ENVOI DES CONSTATS PAR MAIL
- Sans aucun réglage : dans un dossier dont le constat est signé, « Envoyer
  par mail » puis « Ma messagerie » ouvre votre application de mail (Gmail,
  Outlook…) avec le constat en pièce jointe. Les adresses cochées sont
  copiées : collez-les dans le champ « À ».
- Envoi direct en un geste, depuis votre adresse (facultatif, une seule
  fois, 10 minutes, sur un ordinateur) :
  1. Ouvrez script.google.com avec votre compte Google > Nouveau projet.
  2. Remplacez le contenu par celui du fichier outils/envoi-mail-google.gs
     (envoi depuis votre adresse Gmail ; Google ne lui donne que le droit
     d'envoyer), ou outils/envoi-mail-google-alias.gs pour envoyer depuis
     une adresse professionnelle déclarée dans Gmail (« Envoyer des e-mails
     en tant que » ; Google demande alors l'accès complet à Gmail).
     Enregistrez.
  3. Paramètres du projet (roue dentée) > Propriétés du script : ajoutez
     CLE = une phrase secrète d'au moins 12 caractères. Facultatif :
     REPONSE = l'adresse où les propriétaires répondront (version
     standard), ou EXPEDITEUR = l'adresse professionnelle (variante alias).
  4. Déployer > Nouveau déploiement > Application Web ; Exécuter en tant
     que : Moi ; Qui a accès : Tout le monde. Autorisez l'envoi de mails
     (écran « application non validée » : Paramètres avancés > Accéder au
     projet ; c'est votre propre script).
  5. Dans l'application : Réglages > collez l'adresse du déploiement (elle
     finit par /exec) et la clé, puis « Tester l'envoi ».
  Si vous remplacez plus tard le contenu du script : Déployer > Gérer les
  déploiements > crayon > Version : « Nouvelle version » > Déployer.
  L'adresse /exec ne change pas ; sans cette étape, elle continue
  d'exécuter l'ancien script.
- Ne transmettez jamais votre mot de passe ni la clé : ils ne doivent
  figurer ni dans le code de l'application (dépôt public) ni dans un
  message. La clé reste sur la tablette, hors des sauvegardes.
- Sans connexion, le mail attend dans la boîte d'envoi et part au retour
  du réseau ; si le service ne répond pas, de nouveaux essais ont lieu
  automatiquement, espacés. Un même mail n'est jamais envoyé deux fois.
  Tablette perdue : changez CLE dans les propriétés du script.

MISE À JOUR DE L'APPLICATION
- Chaque nouvelle version change le numéro de version à deux endroits :
  VERSION dans index.html et CACHE dans sw.js (par exemple
  'vede-terrain-1.2.1'). Sans ce changement dans sw.js, les appareils déjà
  installés gardent l'ancienne version indéfiniment.
- Publiez tout le contenu du dossier (index.html, sw.js, icons…) dans la
  branche main du dépôt GitHub : GitHub Pages met le site à jour en une à
  deux minutes.
- Sur la tablette : ouvrez l'application une fois avec connexion (elle
  télécharge la nouvelle version et l'annonce), puis fermez-la
  complètement et rouvrez-la. Vos données ne sont pas touchées.
