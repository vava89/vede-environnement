VÉDÉ Terrain, version installable hors connexion (v1.2.1)
=====================================================

Ce dossier contient l'application complète. Une fois installée sur la
tablette, elle s'ouvre et fonctionne sans réseau. Les données (études,
dossiers, anomalies, photos) restent dans la tablette : rien n'est
envoyé sur Internet.

MISE EN LIGNE SUR GITHUB PAGES (une seule fois, 15 minutes environ)
1. Créez un compte sur https://github.com si vous n'en avez pas.
2. Créez un dépôt : bouton New repository, nom « vede-terrain »,
   visibilité Public (le dépôt ne contient que le code de l'application,
   jamais vos données de visite).
3. Dans le dépôt : Add file > Upload files. Glissez TOUT le contenu de ce
   dossier (index.html, sw.js, manifest.webmanifest et les dossiers lib,
   fonts, icons), pas le dossier lui-même. Validez avec Commit changes.
4. Settings > Pages > Build and deployment : Source « Deploy from a
   branch », Branch « main », dossier « / (root) », Save.
5. Après une à deux minutes, l'adresse s'affiche en haut de la page
   Pages : https://VOTRE-COMPTE.github.io/vede-terrain/

INSTALLATION SUR LA TABLETTE
1. Ouvrez l'adresse dans Chrome (Android) ou Safari (iPad), connecté.
2. Chrome : menu ⋮ > « Installer l'application » ou « Ajouter à l'écran
   d'accueil ». Safari : bouton Partager > « Sur l'écran d'accueil ».
3. Lancez l'application une fois depuis son icône, toujours connecté.
   Elle est ensuite utilisable sans réseau.

SAUVEGARDE
- Effacer les données du navigateur ou désinstaller l'application efface
  aussi les études. Exportez chaque étude régulièrement (menu de l'étude >
  Exporter l'étude complète) : le fichier ZIP contient les fiches, les
  photos, le tableau récapitulatif et une sauvegarde restaurable sur
  n'importe quel appareil (accueil > Restaurer une sauvegarde).

MISE À JOUR DE L'APPLICATION
- Chaque nouvelle version change le numéro de version à deux endroits :
  VERSION dans index.html et CACHE dans sw.js (par exemple
  'vede-terrain-1.2.1'). Sans ce changement dans sw.js, les appareils déjà
  installés gardent l'ancienne version indéfiniment.
- Publiez tout le contenu du dossier (index.html, sw.js, icons…) dans la
  branche main du dépôt GitHub : GitHub Pages met le site à jour en une à
  deux minutes.
- Sur la tablette : ouvrez l'application une fois avec connexion (elle
  télécharge la nouvelle version et l'annonce), puis fermez-la
  complètement et rouvrez-la. Vos données ne sont pas touchées.
