# VÉDÉ Terrain
Application de terrain hors connexion pour les contrôles de branchement EU/EP.
Installation : ouvrir https://vava89.github.io/vede-environnement/ sur la tablette, puis « Installer l'application » (Chrome) ou « Sur l'écran d'accueil » (Safari).
Les données saisies restent sur l'appareil ; ne jamais déposer de fichier de données dans ce dépôt.
Le dossier outils/ contient le service facultatif d'envoi des constats par mail, à installer sur votre propre compte Google (mode d'emploi dans LISEZMOI.txt). Il ne contient aucun secret : la clé se règle sur votre compte et sur la tablette.
